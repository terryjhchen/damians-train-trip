# Damian's Train Trip

A train game for phones. Pick a U.S. city or state, pick (or type the name of) a real train that runs there, then steer between tracks to collect 10 stars.

Play it: https://terryjhchen.github.io/damians-train-trip/

The whole game is one file, `index.html`, with no build step. Controls: Go / Back to drive, Left / Right to change tracks, Toot! for the horn (arrow keys and space also work on a computer).
